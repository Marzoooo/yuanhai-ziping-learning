第 1 步 / 5

先认主角：日主是谁？

只需要理解八个字摆放的位置。

01

四柱就像四张标签

把八字分成四组：年、月、日、时。

每组两个字，前一个叫天干，后一个叫地支。先忽略它们的复杂含义。

第 3 柱的第 1 个字 = 日主
这个例子的日柱是乙卯，因此日主是“乙”。

动手试：点上面四个格子，选出日柱。

查看答案（无需交互也能学）

日柱是乙卯，日主是乙。以后遇到任何四柱，都先找第三柱。

会找日主就算过关。

第 3 步 / 5

十神先别背：只有五类关系

所有十神都从“谁对日主做什么”推导出来。

03

把日主想成一棵“甲木”

现在你是甲木。观察别的五行和你的关系：

同我
木 → 甲木同类，像伙伴，也可能竞争。
生我
水 → 甲木水能生木，像补给。古法叫印。
我生
甲木 → 火向外输出。古法叫食伤。
我克
甲木 → 土我可以管理的资源。古法叫财。
克我
金 → 甲木对我形成约束。古法叫官杀。

先把五个大类记住：同类、印、食伤、财、官杀。这一阶段不必分“正”和“偏”。

小练习：甲木日主遇见壬水。水生木，壬水属于哪一大类？

查看答案

答案是印。水生木＝生我。

先会分类，后面再细分。

例1

为什么“七杀”有时会被古书看好？

《喜忌篇》所载史弥远命例 · 古籍署名未作独立史料核验

年柱甲申
月柱丙寅
日柱乙卯主角
时柱辛巳
①先看主角是谁

第三柱是乙卯。第一个字乙，就是乙木日主。先停在这里，不急着看其余七个字。

②再看他处在什么环境

月柱是丙寅，寅是春季的地支，木在春季有支持。日柱是乙卯，卯中藏乙，乙木还有根。古法初步认为乙木有力量基础。

③辛金对乙木做什么？

辛属金，乙属木。金克木，所以辛属于“克我”的官杀一类。乙、辛都属阴，所以辛具体叫七杀。

④丙火对乙木做什么？

木生火，乙木生丙火，丙属于“我生”的食伤一类。乙阴、丙阳，阴阳不同，所以丙叫伤官。

⑤最后看两者怎么相遇

丙是火、辛是金。火克金，丙火对辛金形成克制。古书把这种关系叫“伤官制杀”。

⑥这条案例到底教会了什么？

古人看重的关键条件是：七杀出现后，是否有相应的制约，以及日主有没有根气。这里先按五行相克理解；进阶还需考虑丙辛合等天干关系。

你现在只需要记住：乙木 → 遇辛金（压力） → 丙火制辛金（制约）。
例2

为什么同样“财多”，古书判断不同？

这次要找的区别是：日主有没有力量承担财星。

A · 古书认为有力量任财
年辛丑
月丁酉
日丁巳
时丁未

丁火日主。丁火在天干多次出现；日支巳火，未支也藏丁火，有同类支持。

看点：财虽旺，自己也有力量。
B · 古书认为较难担财
年庚申
月乙酉
日丙申
时丙申

丙火日主，酉月金旺，申金重复；日主丙火虽两透，但缺少明显的火根。

看点：财很旺，自己缺少根气。

一条简单结论：财多只是观察到的现象。古书下一步会追问：“日主能担得起吗？”

例3

只换一个时柱，怎么就“破格”了？

特殊古格经常要求某个地支不能直接出现。先只看两例最后一柱。

A · 壬子／壬子／壬子／壬寅
年壬子
月壬子
日壬子
时壬寅

古法设想：多个子能够“遥冲”出未见的午。这里没有实际出现午。

古书称可讨论虚邀格。
B · 壬子／壬子／壬子／丙午
年壬子
月壬子
日壬子
时丙午

只改时柱，午已经真实出现。古人称这种情况“填实”。

古书认为特殊虚邀条件受破坏。
你来选：哪一个例子发生了“填实”？

查看答案

B：因为原本虚邀的午字，已经在时柱“丙午”里出现。

“虚邀”属于古籍内部的特殊象法规则，适合用于理解文本的条件逻辑，不能把它理解为实际存在的物理作用。

一页复习

整卷反复出现的五种问题

以后忘记格局名字，也可以从下面找入口。

1 · 财特别多

先问：日主有没有力量承担？

2 · 官杀特别强

先问：能承受吗？有没有制化？

3 · 印星在帮忙

先问：这种支持有没有被克坏？

4 · 虚邀 / 拱夹

先问：要求“虚”的字是不是已经出现，或被冲坏？

5 · 一种五行特别集中

先问：气势是否完整，有没有明显破坏条件？

四柱⌄

把出生年、月、日、时写成四组干支；每组两个字。

例：甲申 / 丙寅 / 乙卯 / 辛巳
八字⌄

四柱各两个字，合起来八个字。

例：乙卯是其中一柱。
天干⌄

甲乙丙丁戊己庚辛壬癸这十个字，排列在每柱前面。

例：日柱乙卯中的乙。
地支⌄

子丑寅卯辰巳午未申酉戌亥这十二个字，排列在每柱后面。

例：日柱乙卯中的卯。
日主 / 日干⌄

日柱上面的那个天干，所有判断都以它为中心。

例：乙卯日的日主是乙。
月令⌄

月柱的地支所代表的季节气候和当令气势。

例：丙寅月先看寅。
得令⌄

日主的五行得到季节支持；这只是旺衰判断的一部分。

例：乙木在寅卯等春月，通常有季节帮助。
通根 / 有根⌄

某天干的五行在地支藏干中有对应根气。

例：乙卯日，卯中藏乙，乙木有根。
旺 / 弱⌄

古法综合季节、根气、帮扶、制泄判断力量状态。

例：只看一个天干，不能直接定旺弱。
十神⌄

其他天干、藏干与日主的五行和阴阳关系，共分十类。

例：乙日见辛，辛是七杀。
比肩 / 劫财⌄

与日主同一五行；阴阳相同叫比肩，异叫劫财。

例：甲遇甲比肩，甲遇乙劫财。
正印 / 偏印⌄

其他五行生我，是补给一类；阴阳异为正印、同为偏印。

例：甲日遇癸为正印，遇壬为偏印。
食神 / 伤官⌄

日主生出的五行，是输出一类；阴阳同为食神、异为伤官。

例：乙日遇丙是伤官。
正财 / 偏财⌄

日主克的五行，是需要管理的资源；阴阳异为正财、同为偏财。

例：甲日遇己为正财，遇戊为偏财。
正官 / 七杀⌄

克日主的五行，是约束一类；阴阳异为正官、同为七杀。

例：乙日遇辛是七杀。
制杀⌄

用食神或伤官等克制七杀，古法认为可能缓和杀的压力。

例：乙日丙火克辛金。
化杀⌄

七杀通过印星等相生关系转为对日主有帮助的结构。

例：先辨杀与印能否形成生化。
藏干⌄

地支中按传统规定包含的一到三个天干。

例：寅藏甲、丙、戊。
透干⌄

某个藏在地支里的天干同时出现在四柱天干中。

例：辰藏戊，四柱天干又见戊。
格局⌄

古人给某种组合条件起的分类名称。

例：正官格、炎上格等。
用神⌄

合 / 冲 / 刑⌄
